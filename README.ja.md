## デモ
ブラウザで動作する実行環境 [Wirth Playground](https://code4fukui.github.io/Wirth/)

## 特徴
- 学びやすく、削ぎ落とした構造化プログラミング言語
- Pascalの開発者であるニクラウス・ヴィルト（Niklaus Wirth）氏にインスパイアされた
- シンプルさと優雅さを体現し、教育用構造化プログラミングのために設計されている

## 使い方
Wirthはプログラミング言語であり、実行環境（ランタイム）で動作します。本リポジトリには、ブラウザで動作する実行環境とCLIのサンプルが含まれています。
