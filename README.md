## Features
- Easy-to-learn, sleek structured programming language
- Inspired by the creator of Pascal, Niklaus Wirth
- Embodies simplicity and elegance, designed for educational structured programming

## Usage
Wirth is a programming language, so it can be run in a runtime environment. The repository includes a web-based runtime as well as CLI examples.
